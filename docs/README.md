# Documentación del Proyecto - CancerLiver AI

Estructura modular alineada con los bloques del documento oficial de planificación (`res/planning.doc`):

- **[`01-requisitos/`](./01-requisitos/)**: Introducción, objetivos generales, Lean Canvas, requerimientos funcionales (RF), requerimientos no funcionales (RNF) y restricciones.
- **[`02-costes/`](./02-costes/)**: Estimación de costes y esfuerzo (Parkinson, Pricing to Win, Puntos Objeto).
- **[`03-riesgos/`](./03-riesgos/)**: Identificación, priorización, planes de contingencia y seguimiento.
- **[`04-rrhh/`](./04-rrhh/)**: Estructura organizativa del equipo y roles (DD, DC, CC).
- **[`05-agenda/`](./05-agenda/)**: WBS, precedencias, hitos, asignación y cronogramas (MS Project).
- **[`actas/`](./actas/)**: Registro de acuerdos, reuniones internas y decisiones técnicas.
